ByPassing Read-Only Memory and Why mseal() is needed

May 19, 2026

As one may be familiar, the MMU (Memory Management Unit) enforces and supports memory protection such as marking a page to be READ-ONLY (RO). But it turns out there is an API mprotect() that allows us to change the access protection of the calling process’s memory pages. Thus mprotect() could be used to mark pages marked for RO as writable or executable, an undesirable behavior for any critical program as attackers could utilise this weakness to write custom payloads to either gain rootshell or bypass local checks.
